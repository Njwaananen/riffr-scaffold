Product Requirements Document
Title: Riffr 

Riffr is a mobile app that helps musicians, producers, and vocalists connect and collaborate through a swipe based discovery system. The app is designed for hobbyist and semi-professional artists to find creative partners, share audio samples, and communicate to create music together.

Technical Structure
• Frontend: Flutter (mobile-first, Android/iOS)
 • Backend: Firebase (Firestore, Authentication, Cloud Storage)
 • Tools: GitHub, Windsurf, VS Code
• Constraints: Mobile only, no large file hosting, audio preview under 10MB~

Core Features
• Create & Manage Profiles - Allows users to set musical role, genre, skills, and upload sample audio 
• Discover & Find Collaborators - Includes swipe-style matching, search, and filtering by genre or skill 
• Connect & Collaborate - Enables chat with short audio demo sharing
 • Receive Notifications - Alerts for messages, matches, and new users in the same genre
 • Manage Account - Secure sign-in, password reset, and logout

Targeted Users
 • Hobbyist Musicians (ages 16–30) - Seek creative connections and easy discovery 
• Semi-Professional Creators (ages 25–40) - Producers or freelancers seeking quality collaborations
• Independent Producers/Engineers (ages 20–40) - Want access to vocalists and songwriters for projects

Usage Context(s)
• Mobile-first experience optimized for quick collaboration
• Used at home, in home studios, dorms, and small recording spaces
• Requires active internet connection, offers no offline support

Scope 
The first scope includes setting up the project repository, establishing structure for future development, and scaffolding the backend and frontend architecture. The app currently focuses on profile, discovery, chat, etc.
